# Политика безопасности One Director

> **Дисклеймер.** One Director — инструмент скрининга. Флаг или риск-скор означает «признаки возможного нарушения, требуется проверка», а не доказательство нарушения. Любое решение принимает инспектор Комитета по конкуренции после собственной проверки.

## Как сообщить об уязвимости

1. **Основной канал** — GitHub → вкладка *Security* → *Report a vulnerability* (приватное сообщение, видно только мейнтейнерам). Не создавайте публичный issue.
2. **Резервный канал** — security-контакт команды Rigged? (адрес будет указан здесь до публикации репозитория; см. открытые вопросы в отчёте Фазы 0).
3. Что приложить: описание, шаги воспроизведения, затронутые версия/коммит, оценка последствий. **Не прикладывайте реальные персональные данные** — опишите, какие поля затронуты.
4. Не проверяйте уязвимость на чужих данных и не обращайтесь массово к etender.uzex.uz — используйте локальный стенд с `DEMO_MODE=true` и синтетическими данными.

### Сроки ответа

| Этап | Срок (обычный) | Во время хакатона (2–4.12.2026) |
|---|---|---|
| Подтверждение получения | 3 рабочих дня | 12 часов |
| Первичная оценка и уровень критичности | 7 дней | 24 часа |
| Исправление критической / высокой | 14 / 30 дней | до конца хакатона или отключение функции |
| Публикация информации | после исправления, по согласованию с автором | — |

Добросовестных исследователей, соблюдающих эту политику, мы благодарим в описании исправления (если они согласны).

## Что считается уязвимостью

- Доступ к немаскированным ИНН, именам ИП/физлиц или псевдонимам людей сверх прав роли; любой немаскированный идентификатор в `DEMO_MODE`.
- Обход аутентификации или ролевой модели, подделка JWT, повышение привилегий.
- SQL-инъекция, XSS (в дашборде, графе, PDF), path traversal, SSRF.
- Prompt injection, из-за которой справка меняет смысл, формат или содержит обвинение, ИНН или выдуманные факты.
- Утечка секретов (ключи, `PSEUDONYM_SALT`) через логи, ответы, ошибки, образ Docker, историю git.
- Подмена или удаление записей `audit_log` без обнаружения.
- Возможность подменить данные/справку так, что инспектор увидит ложные факты о фирме.
- Уязвимые или вредоносные зависимости в lock-файлах.

**Не считается уязвимостью:** ложноположительный флаг сам по себе (это ограничение модели — сообщайте как баг, см. `docs/model-card.md`), отчёты сканеров без доказанного влияния, атаки, требующие физического доступа к ноутбуку команды, социальная инженерия против команды.

## Меры защиты (кратко)

| Область | Меры | Документ |
|---|---|---|
| Угрозы | STRIDE-анализ активов и участников, 8 ключевых сценариев | [docs/threat-model.md](docs/threat-model.md) |
| Персональные данные | минимизация, HMAC-псевдонимы людей, маскирование, `DEMO_MODE`, локализация в РУз, сроки хранения | [docs/data-protection.md](docs/data-protection.md) |
| Секреты | только env / pydantic-settings, fail fast, gitleaks + detect-private-key, процедура отзыва | [docs/incident-response.md](docs/incident-response.md) |
| Сбор данных | только публичные эндпоинты, ≤ 1 запрос/с, стоп при 429/403, TLS, лимиты | [docs/scraping-policy.md](docs/scraping-policy.md) |
| LLM | данные как JSON в разделителях, без инструментов, строгая схема ответа, проверка фактов, справочник статей | [docs/llm-safety.md](docs/llm-safety.md) |
| Доступ | 4 роли, JWT 15–60 мин, argon2id, проверка роли на сервере, матрица доступа | [docs/access-control.md](docs/access-control.md) |
| API и веб | валидация, параметризованный SQL, белые списки, rate limiting, CORS, заголовки безопасности, экранирование | [specs/api-contract.md](specs/api-contract.md) |
| Аудит | append-only `audit_log` с цепочкой хешей, JSON-логи с фильтром ПДн | [docs/access-control.md](docs/access-control.md) |
| Модель | человек в контуре, evidence у каждого флага, версия модели, скрытые пороги | [docs/model-card.md](docs/model-card.md) |
| Цепочка поставок | pin + хеши + отсечка по дате релиза, pip-audit, Dependabot, ruff (S), bandit, mypy | [README.md](README.md) |
| Контейнер | slim, multi-stage, non-root, read-only, no-new-privileges, порты на localhost | [README.md](README.md) |
| ИИ-агенты | `.claude/settings.json`, worktree на агента, PR-only, данные ≠ инструкции | [CLAUDE.md](CLAUDE.md) |

## Поддерживаемые версии

До пилота поддерживается только ветка `main`. Исправления безопасности не бэкпортируются.
