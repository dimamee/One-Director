## D-20. Офлайн-интеграция (если на площадке нет интернета)

1. Создать локально ветку `integration` от последнего `main`.
2. Каждый агент работает как обычно в своей ветке; вместо PR — локальный merge в `integration` после:
   - `pre-commit run --all-files` — зелёный (включает gitleaks, ruff, mypy, bandit);
   - `pytest` — зелёный;
   - вердикт ревьюера 09 записан в сообщении merge-коммита.
3. `pip-audit` офлайн не работает — новые зависимости во время офлайна **не добавляются**.
4. Демо запускается с ветки `integration`.
5. Как только появилась связь: `git push origin integration`, PR `integration → main`, полный CI. Merge — только после зелёного CI.
