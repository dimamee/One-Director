# Задача: дашборд инспектора на Streamlit

**Роль:** frontend-разработчик.

**Вход:** API (`specs/api-contract.md`) по адресу `API_BASE_URL`; `docs/glossary-uz-ru.md` (термины uz/ru); `docs/access-control.md`.

**Выход:** `app/main.py` и модули в `app/`:
- вход (логин → JWT в `st.session_state`, не в URL и не в cookies);
- очередь рисков (фильтры и сортировка — только значения из белых списков API);
- карточка лота: факты, флаги с evidence, скор и топ-3 причины, справка uz/ru с пометкой источника (ИИ/шаблон), **исходные цифры рядом со справкой**, дисклеймер;
- карточка фирмы и граф — переход по `firm_ref` из карточки лота (работает и в `DEMO_MODE`, D-17), граф (pyvis), карта регионов (plotly), кнопка экспорта PDF (только `supervisor`);
- переключатель языка ru/uz.

**Готово, когда:**
- [ ] Дашборд получает данные **только через API**; в `app/` нет импорта `duckdb`, чтения `data/`, чтения секретов.
- [ ] Все строки из данных экранируются; нет небезопасного HTML-рендеринга (`unsafe_allow_html` с данными, `components.html` с данными) — проверяет хук pre-commit и тест.
- [ ] Подписи узлов pyvis экранируются (`html.escape`) до передачи в pyvis; во всплывающих подсказках — только текст.
- [ ] В `DEMO_MODE` поверх интерфейса виден баннер «Демо-режим: данные замаскированы».
- [ ] Все тексты интерфейса — из глоссария, формулировки «признаки возможного нарушения».
- [ ] Сняты `skip` с XSS-тестов дашборда.
- [ ] ruff, mypy (по возможности), pytest зелёные.

**Тесты:** `tests/app/` — XSS-строки в названиях фирм/лотов (`tests/security/test_xss_escaping.py`), отсутствие прямого доступа к данным, фейковый API-клиент.

**Можно менять:** `app/`, `tests/app/`; в `tests/security/` — только удаление маркеров `skip` своей волны (D-16).

**Нельзя менять:** API и его контракт; `security/`; `docker-compose.yml` (через PR людям).

**Требования безопасности:**
- **Экранирование** всех строк из данных (названия фирм и лотов могут содержать HTML/JS).
- **Маскирование в демо-режиме** выполняется сервером; фронт не пытается «раскрыть» данные и не кэширует ответы со снятой маской.
- **Без `unsafe_allow_html=True`** для любых данных.
- Токен — только в памяти сессии; выход очищает сессию.
- Без внешних CDN, трекеров, аналитики (`browser.gatherUsageStats=false`).
- Ошибки API показываются общим текстом без деталей.
