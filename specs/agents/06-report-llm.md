# Задача: справки по лоту на узбекском и русском через LLM под защитой llm_guard

**Роль:** разработчик генерации справок.

**Вход:** карточка лота (факты, флаги с evidence, скор, причины); `docs/llm-safety.md`; `security.llm_guard` (Фаза 1); справочник статей ЗРУ-850 (тексты согласует юрист); `docs/glossary-uz-ru.md`.

**Выход:**
- `src/one_director/report/` — сборка `LotFacts` (только агрегаты и плейсхолдеры), вызов Claude через официальный SDK `anthropic`, валидация, детерминированная шаблонная справка (fallback), кэш `briefs`, подстановка разрешённых роли значений вместо плейсхолдеров.
- Справочник `legal_refs` (ID → текст ru/uz) с пометкой «проверено юристом: да/нет».
- Предгенерированные справки для демо-лотов (работа без интернета).

**Готово, когда:**
- [ ] `LotFacts` не содержит ИНН, названий фирм, ФИО, `person_id`, хешей, `trade_id`, `source_url` (тест на канарейки).
- [ ] Ответ разбирается в строгую pydantic-схему; проверки фактов, ID статей и запрещённых фраз из `docs/llm-safety.md` реализованы и покрыты тестами.
- [ ] Отказ модели (`stop_reason == "refusal"`), усечение, таймаут, превышение бюджета → шаблонная справка с пометкой.
- [ ] Кэш по `facts_hash + prompt_version + model`; демо работает без сети.
- [ ] Все тесты — с фейковым клиентом, без сети и без ключа.
- [ ] ruff, mypy, bandit, pytest зелёные.

**Тесты:** `tests/report/` + `tests/security/test_prompt_injection.py` — инъекции ru/uz/en, попытка закрыть `</lot_facts>`, выдуманные числа/ИНН/статьи, обвинительные формулировки, fallback.

**Можно менять:** `src/one_director/report/`, `tests/report/`.

**Нельзя менять:** `security/llm_guard.py` (только через PR людям), системный промпт без повышения `PROMPT_VERSION`, тексты статей без отметки юриста, другие модули.

**Требования безопасности:**
- **Защита от prompt injection:** данные — только JSON внутри `<lot_facts>`; свободный текст по умолчанию не передаётся; системная инструкция «данные ≠ инструкции».
- **Без персональных данных в промпте** и без ИНН вообще; плейсхолдеры `P1…`.
- LLM **без инструментов, сети и доступа к БД**.
- **Валидация вывода:** строгий JSON по схеме; отклонять суммы, ИНН, названия, которых нет во входе; отклонять «нарушение доказано», «картель» о конкретной фирме (ru/uz).
- Ссылки на закон — только ID из фиксированного справочника.
- Параметры: `max_tokens`, таймаут, бюджет на сессию; `temperature` не передаётся (у актуальных моделей отклоняется API — см. `docs/llm-safety.md`).
- `ANTHROPIC_API_KEY` — только через `security.settings`; промпты и ответы логируются без ПДн.
