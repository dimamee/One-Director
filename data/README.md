# data/ — локальные данные (не в git)

В git хранится только этот файл. Всё остальное в `data/` игнорируется (`.gitignore`), не попадает в образ Docker (`.dockerignore`), а `data/raw/` недоступен для чтения ИИ-агентам (`.claude/settings.json`).

| Папка | Что | Срок хранения |
|---|---|---|
| `data/raw/` | сырые ответы площадки и реестра (JSON) | удаляются после успешной обработки, не позже 7 дней |
| `data/processed/` | Parquet и DuckDB (`one_director.duckdb`): лоты, заявки, фирмы, псевдонимы, флаги, скоры, справки, `audit_log` | срок пилота + 1 год (см. `docs/data-protection.md`) |

Папки создаются пайплайном при первом запуске (`mkdir -p data/raw data/processed`).

Правила:
- Реальные данные — только на машине команды (демо) или на сервере в Узбекистане (пилот); не копировать в облака, чаты, ноутбуки с выводом.
- ФИО людей в `data/` не хранятся никогда — только псевдонимы `person_id`.
- Для тестов используются только обезличенные фикстуры в `tests/fixtures/`.
- Бэкапы — см. README, раздел «Размещение данных и резервные копии».
