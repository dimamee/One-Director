# notebooks/ — исследовательские ноутбуки

Правила:
- **Без секретов:** ключи не вставляются в ячейки; настройки — только через `one_director.security.settings`.
- **Без персональных данных:** только синтетика или обезличенные фикстуры; реальные выгрузки в ноутбуках не открывать.
- **Перед коммитом очищайте выводы** (Kernel → Restart & Clear Output или `jupyter nbconvert --clear-output --inplace <файл>`): выводы ячеек — главный путь утечки данных и ключей.
- Ноутбуки не попадают в образ Docker (`.dockerignore`) и не являются частью продакшн-кода: полезный код переносится в `src/` с тестами.
- Временные копии — в `notebooks/scratch/` (игнорируется git).
- Метрики, посчитанные на синтетике и на реальных делах, подписываются и не смешиваются.
